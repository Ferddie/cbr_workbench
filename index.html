How similarity is calculated

Local, categorical field
sim(a, b) = 1 if a = b, otherwise 0

Capital letters and extra spaces are ignored.

Local, numeric field
sim(a, b) = 1 − |a − b|range

range = highest minus lowest value of the field, including the new case, so every local similarity stays between 0 and 1.

Global
sim(A, B) = 1Σ wi · Σ wi · simi(a, b)

a = new case value, b = stored value, w = field weight. A blank stored value scores 0 for that field.

The CBR cycle here

  1. Retrieve the stored cases closest to the new case.
  2. Reuse the solution of the most similar case.
  3. Revise that solution if it does not fit.
  4. Retain the confirmed case for future searches.
